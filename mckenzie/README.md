# McKenzie Nearby

Local vacation guide for the **McKenzie River corridor** (Vida · Rainbow · McKenzie Bridge · Clear Lake).

**Path:** `/mckenzie/`  
**Future domain idea:** `mckenzienearby.com`

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Hub + filterable directory |
| `things-to-do.html` | Waterfalls, Blue Pool, Clear Lake, soaks |
| `restaurants.html` | Corridor food stops |
| `where-to-stay.html` | How to choose a base (includes mid-corridor river stays) |
| `blog/mckenzie-river-weekend-itinerary.html` | Weekend plan |

## Soft lodging placement

Lodging is presented as traveler advice by corridor section (headwaters / hot springs / mid-corridor). Vida View Resort appears as one mid-corridor riverfront option alongside Belknap, Clear Lake, and campgrounds — same card style, useful logistics notes, link to [vidaviewresort.com](https://vidaviewresort.com).
